# SelfTrain

[English](README.en.md) | 简体中文

一个单用户、本地运行的学习刷题工具：把外部 Agent 生成的 JSONL 导入题库，逐题限时作答，记录首次成绩与间隔复习表现。它不调用 AI 服务，也不需要账户或密钥。

## 已实现

- 批量导入四选一 JSONL，每次最多 5000 道非空题目（空行不计数）；整批结构校验，相同 ID/内容跳过，冲突不覆盖历史。
- 每轮目标 30 题，一次显示一道，按题目时限计时；刷新与切换标签不暂停。
- 到期题优先、新题随机；选项洗牌，答后展示正确答案和解析。
- 首次答对间隔复现一次；答错、超时或放弃的题持续间隔复现，直到后来答对。
- 本机 SQLite 持久化，首次/复习成绩分开，按主题与日期统计并保存作答历史。
- 完整 JSON 备份导出与覆盖式恢复；坏备份不改变现有数据。

## 快速开始

要求 Node.js 22.12 或以上和 npm。已在 macOS、Node.js 25.9 / Go 1.25.5 环境下验证；运行应用不需要安装 Go。进入项目根目录后安装依赖：

```bash
npm install
```

启动开发版：

```bash
npm run dev
```

打开 **http://127.0.0.1:5173**。在“导入题目”页点击“导入 Go 示例题”，或多选/拖入自己的 `.jsonl` 文件；回到工作台即可开始一轮。

出题 Agent 应先生成临时 ID 草稿。首次使用时选择 0–1023 范围内未被其他生成器占用的 Agent ID，并在之后持续复用仓库内自动忽略的状态文件：

```sh
npm run assign-ids -- --agent-id 17 --input draft.jsonl --output questions.jsonl
```

把 `questions.jsonl` 导入 SelfTrain。独立状态文件或不同机器必须使用不同 Agent ID；不要删除状态文件后继续复用原 Agent ID。

后端健康检查：

```bash
curl http://127.0.0.1:8787/api/health
```

成功时返回 `{"ok":true}`。

### 构建后单服务运行

```bash
npm run build
```

```bash
npm start
```

打开 **http://127.0.0.1:8787**。此时不需要另外启动 Vite；应用运行时不依赖外部字体、图片或 AI API。

## 作答与复现规则

1. 开始前可筛选语言/主题；到期题按最早到期优先，再随机补新题，最多 30 道。可用题不足时正常结束，同一轮不重复同题。
2. 当前题显示即开始计时。提交时按服务端的截止时间判定；超时单独标记为 `timeout`，不是“选错”，但属于未通过。超时同步遇到短暂网络中断时，应用会自动重试；超时判定仍以服务端已记录的截止时间为准。
3. 提交后停表，显示对错、用户当次所见的正确选项字母和解析；点击“下一题”才进入下一道。
4. 只有一轮可处于进行中。重开网页恢复原轮和截止时间；多标签页的过期操作会被拒绝，随后同步最新轮次，不会把上一题的选择写进下一题。读取已结束轮次的总结失败时，可以重试。
5. 提前结束时，当前已显示但未提交的题记为“放弃”；没有打开的题不记分。已经提交的记录始终保留。

| 当前阶段 | 本次结果 | 后续安排 |
| --- | --- | --- |
| 新题首次作答 | 答对 | 间隔后复现一次 |
| 新题首次作答 | 答错 / 超时 / 放弃 | 进入错题复现 |
| 首次答对后的复现 | 答对 | 不再出现 |
| 任意复现 | 答错 / 超时 / 放弃 | 重新间隔后复现 |
| 错题复现 | 答对 | 不再出现 |

全局复现间隔默认 **滚动 24 小时**，可设为 1–720 小时；从该次作答结束时刻计算。修改设置只影响之后的安排，不追溯修改已经记录的到期时间。

正确率中“首次作答”只统计每题的第一次尝试，“复现”另有分母；超时与放弃计入未通过，未打开题不计入分母。平均耗时包含该阶段的已记录尝试。日统计采用运行服务器的本机日期，历史页显示最近 100 次尝试、最近 30 个有作答的日期和最近 12 轮；数据库与备份保存完整历史。

## 数据与配置

默认数据库在 **`data/selftrain.sqlite`**，目录首次启动时创建。重启网页或服务不会丢失结果。`data/`、构建产物与依赖已加入 `.gitignore`。

| 环境变量 | 必填 | 默认 | 用途 |
| --- | --- | --- | --- |
| `SELFTRAIN_DATA_DIR` | 否 | 项目根目录下 `data/` | SQLite 数据所在目录 |
| `SELFTRAIN_PORT` | 否 | `8787` | 本地 API / 构建版页面端口，优先于 `PORT` |
| `PORT` | 否 | 未设定 | 仅构建版可接受运行环境分配的端口；开发版忽略它 |
| `NODE_ENV` | 否 | 开发模式 | `npm start` 自动设为 `production`，服务构建后的页面 |

如要使用单独的数据目录：

```bash
SELFTRAIN_DATA_DIR=/absolute/path/to/selftrain-data npm run dev
```

`.claude/launch.json` 的开发预览使用 **`data/preview/`**，构建版验证预览使用 **`data/production-check/`**，两者都与直接执行 npm 命令产生的个人学习数据库隔离。预览内的演示记录不会污染默认数据库。

### 备份与恢复

在“数据与设置”页下载完整 JSON 备份，包含题库、完整作答历史、复现状态、已结束轮次与设置。换电脑时把备份带到新实例并恢复即可。进行中的轮次必须先结束才能备份/恢复。

恢复会**替换**而非合并当前全部数据，操作前有确认提示；建议先导出当前备份。服务端在替换前检查格式和版本、题目内容哈希、选项排列、引用关系、首次作答到复现的阶段顺序，以及轮次进度和时间一致性；符合约束的 version 1 备份仍可恢复，写入失败时事务回滚。不要手工修改备份；恢复文件上限 50 MB。

不要在服务运行时只复制 `.sqlite` 文件而忽略 SQLite 的 WAL 文件；优先使用应用提供的完整备份。

## 技术结构

React + Vite 提供页面，Fastify 执行导入、组卷、计时和判分，`better-sqlite3` 存储所有状态。题目被打开时，服务端持久化选项排列及绝对截止时间；提交答案与安排复现在同一事务中执行。答题 API 在提交前不发正确答案或解析。

```text
src/                   页面、可访问的四选一组件及样式
server/                本地服务与 SQLite 建表
server/domain/         导入、调度、答题、统计、备份
shared/                题目格式和前后端类型
examples/              30 道 Go 示例 JSONL
docs/                  使用规范和已确认需求
tests/                 领域、API 与界面测试
```

主要界面控件改造自 Uiverse 官方公开组件仓库；保留了作者和 MIT 许可文本，补上原片段缺少的键盘焦点与语义化单选。详见 [第三方声明](THIRD_PARTY_NOTICES.md)。

## 边界与安全

- **信任出题 Agent 的标准答案。** 系统只检查 JSONL 结构，运行时不验证 Go 程序，也不提供题目纠错、作废或答案编辑。因此错误标准答案可能反复出现并影响统计，这是首版明确保留的限制。
- 仅支持四选一单选题。无多选题、代码执行、AI 出题接口、用户登录或云同步。
- 本地服务仅监听 `127.0.0.1`，拒绝外部 Host / Origin 的写请求，Markdown 不执行 HTML，也不自动加载题干中的远程图片。**不要把此无认证服务暴露到公网。**
- 备份中包含全部学习内容和历史，按私人文件保管。
- 支持长期本机存储，但不会自动提供异地备份；请定期手动导出。
