# SelfTrain 题目 JSONL 规范（v1）

每行是一道独立的 UTF-8 JSON 对象。**不是 JSON 数组**，不要添加 Markdown 代码围栏、注释或标题。文件扩展名为 `.jsonl`；允许 UTF-8 BOM、LF 或 CRLF 换行、空行和末尾换行。空行不计入题目数量。题干和解析中的换行必须在 JSON 文本中写作 `\n`（两个字符：反斜杠和字母 n）；解析 JSON 后会还原成实际换行。推荐把含实际换行的字符串交给 `JSON.stringify` 序列化，不要预先手动转成字面量 `\n` 再序列化，以免双重转义。每道题仍须占一条物理行。

## 必填字段

| 字段 | 类型 | 约束 / 含义 |
| --- | --- | --- |
| `id` | 字符串 | 字符串形式的稳定唯一 ID；本地 Agent 出题建议用仓库提供的雪花 ID 工具分配。已导入题目不可用同一 ID 替换内容。 |
| `language` | 字符串 | 学习语言或学科，如 `Go`；1–80 字符，用于筛选和统计。 |
| `topic` | 字符串 | 知识主题，如 `数组与切片`；1–120 字符。 |
| `stem` | 字符串 | 题干；可用 Markdown 及围栏代码块，1–12000 字符。不要写“选项 A 中的代码”等依赖选项字母的位置提示，因为每次作答会随机调整选项顺序。 |
| `options` | 对象 | 恰好包含 `A`、`B`、`C`、`D` 四项，每项是 1–4000 字符的字符串；去除前后空白后，四项内容须互不相同。 |
| `answer` | 字符串 | `A` / `B` / `C` / `D` 之一，指向文件中**原始** `options` 的键。 |
| `explanation` | 字符串 | 标准答案的原因，可用 Markdown；1–12000 字符。提交或超时后展示。 |
| `duration_seconds` | 整数 | 本题作答时限，1–3600 秒；建议普通语法题设为 45–120 秒。题目显示时开始倒计时，切走或刷新不暂停。 |

可选字段：`tags`（最多 12 个、每个 1–50 字符的字符串数组）、`go_version`（最多 40 字符的适用 Go 版本，例如 `1.25`）。除上述字段外的字段会报错；字段中的前后空白会去除。题干与解析支持 Markdown，但 HTML 标签不会被执行或当成可信代码。

## 单行示例

```jsonl
{"id":"go-syntax-v1-001","language":"Go","topic":"变量与常量","stem":"以下代码输出什么？\n```go\nx := 1\nx, y := 2, 3\nfmt.Println(x, y)\n```\n假设位于函数体内，且已导入 fmt。","options":{"A":"1 3","B":"2 3","C":"编译失败：x 已经声明","D":"2 0"},"answer":"B","explanation":"短变量声明允许同一作用域中的已有变量与至少一个新变量共同出现在左边。","duration_seconds":60,"tags":["短变量声明"],"go_version":"1.25"}
```

可直接导入的完整示例见 [`examples/go-syntax.jsonl`](../examples/go-syntax.jsonl)，共有 30 道 Go 语法题。需要 Agent 批量出题时，可用 [`AGENT_PROMPT.md`](AGENT_PROMPT.md) 的指令。

## 导入及重复规则

- 单次可选择多个文件，一批合计最多导入 5000 道非空题目、5 MB；超过数量上限时会指出第 5001 道非空题目所在的物理行号。无效 JSON、缺字段、无效答案、重复选项或 ID 内容冲突会返回文件名和物理行号；**整批文件都不写入**。
- 同 ID 且内容完全相同会跳过；不同 ID 的规范化题目内容相同也会跳过，原题和作答历史不变。同 ID 内容变化会使整批报冲突。
- 系统仅检查**结构**，不会自动运行代码或证明 Agent 的答案正确。首版不提供题目纠错或作废功能；生成端应先自行核对答案。
- 一轮目标 30 题；先取到期复现题，再随机补新题。首次答对间隔后再出现一次；曾答错、超时或放弃的题按间隔持续复现，直到之后答对一次。全局间隔默认 24 小时，与每题的 `duration_seconds` 无关。

## 多文件与 ID 工具

导入页支持多选或拖入多个 JSONL 文件，一次校验和提交；结果会列出每条重复题的位置与命中目标。生成工具用法：`npm run assign-ids -- --agent-id 1 --input draft.jsonl --output questions.jsonl`。首次运行会在当前目录创建 `.selftrain-id-state.json` 持久状态；相同 Agent ID 的所有生成任务必须共用该状态文件。多台机器或独立状态文件必须分配不同的 Agent ID（0–1023）。工具会先预留并保存 ID，再写最终 JSONL；不要删除或复制状态文件来复用已用过的 Agent ID。
