# SelfTrain 首版需求（已确认）

确认日期：2026-10-05。需求通过 grill-me 多轮访谈确认，本文件保留首版的产品边界，避免后续迭代误改规则。

## 用户与输入

- 单用户、本机 Web 应用；以命令行启动，不要求桌面安装包、账户、云同步。
- 题目由外部 Agent 生成，系统不内置生成模型。JSONL 批量导入；首版只有 A/B/C/D 四选一单选题。
- 每题提供稳定 ID、语言、主题、题干、正确答案、解析和倒计时秒数；题干/解析支持代码块。
- 先信任 Agent 答案正确；不做人工预览、语义审核或答案纠错/作废。ID 相同但内容不同不自动覆盖。
- 导入整文件成功或整文件拒绝；相同旧题可跳过，错误给出行号。

## 答题

- 每轮固定目标 30 题；到期题优先（按到期时间），新题随机补足；可按语言/主题筛选。
- 一次只显示一道题。倒计时由 Agent 随题提供，显示即开始，不因切走或刷新而暂停。
- 提交即停表并反馈对错、正确选项和解析；用户点击下一题后才继续。
- 超时记“超时未答”，进入错题复现；提前结束时当前已打开未提交的题记“放弃”，未打开题不记分。
- 30 题完成、无可用题或主动结束时显示本轮总结。只有一轮可同时进行，重开恢复原轮。
- 每次作答随机排列选项，保存当次排列和选择，以免仅记住答案字母。

## 复现

- 首次答对的题间隔后复现一次；复现答对则停止，复现答错转入错题循环。
- 曾答错、超时或放弃的题间隔复现，直到之后答对一次才停止。
- 间隔全局可设，默认滚动 24 小时，允许 1 小时至 30 天；每次按该次结束时间重新安排。
- 设置改变只影响以后安排，不追溯既有到期时间；未到期旧题不提前出现，同一轮不重复同题。

## 评估与数据

- 首次作答成绩与复习表现严格分开；复习不回写首次成绩。
- 展示首次正确率、按主题统计、平均用时、待复现数量、日期/作答历史及轮次总结，不构造不透明能力分。
- 所有结果与复现状态持久化到本机数据库。
- 支持完整备份导出和覆盖恢复，恢复前确认；进行中的轮次先结束。

## 交付

- 可运行应用、安装/运行说明、题目规范、外部 Agent 出题指令和 30 道 Go 常见语法示例。
- UI 尽量复用 Uiverse 组件，允许为可访问性、四选项和业务状态做适配，保留许可与作者来源。
